03 · 随机化校验

A/B test 可信度的第一道关：验证两组用户画像是否均衡。若分组不随机，后续差异就不能归因于页面改版。

检验方法：年龄用 Welch t 检验 + 标准化均值差（SMD）；类别变量用卡方独立性检验。全部 p > 0.1，SMD ≈ 0 → 分组均衡。

04 · 转化率假设检验

原假设 H₀：pnew = pold；显著性水平 α = 0.05。用三种方法互相印证。

分组转化率对比（误差棒 = 95% CI）
转化率随时间走势（14 日滚动均值）

整个实验周期（2023-08 ~ 2025-08）内，两组转化率持续分离，新页的优势不是某段时期的偶然波动。

Bootstrap 差值分布（2000 次重抽样）

橙色虚线为观测差 +6.08pp，青色带为 95% 置信区间 [+5.63pp, +6.49pp]，远离 0。

功效曲线：不同样本量下能检测出的提升

红色虚线为当前样本量。功效充足：最小可检测提升仅 ±0.34pp（α=0.05，功效 0.8）。

辅助指标：浏览深度（log 变换后检验）

两个辅助指标均不显著 → 新页改变了「是否购买」，但没有改变浏览深度。转化提升不是「多逛出来的」。

05 · 用户研究：异质性分析

总体显著 ≠ 所有人提升一样大。按设备 / 性别 / 年龄 / 地区分群检验，并用 Logistic 回归交互项做严谨的异质性判断。

Logistic 回归交互项：新页 × 用户特征（OR 森林图）

交互项 OR 全部接近 1 且不显著（最小 p ≈ 0.24）→ 处理效应在所有人群间几乎完全均匀，不存在异质性。

06 · 结论与业务建议

  1. 新页显著提升转化率：11.87% → 17.95%，绝对 +6.08pp、相对 +51.2%。z = 46.3，p < 0.001；卡方与 Bootstrap（95% CI [+5.63, +6.49]pp）一致。
  2. 无用户异质性：18 个分群（3 设备 + 3 性别 + 5 年龄段 + 7 地区）提升全部落在 +5.3 ~ +6.4pp，Logistic 交互项全部不显著 → 不需要定向灰度。
  3. 建议全量上线新页，并持续监测：① 转化率是否随时段/季节回落；② 长期指标（复购率、LTV）——确认提升是增量而非「前移」了购买。
局限与自我审视：① 分群多次检验有假阳性风险，本次结论以交互项为准（全部不显著），与逐群检验一致，结论稳健； ② 实验工程环节（AA 校准、SRM、时段效应、SUTVA）已在 07 附录用数据回测通过；生产环境仍建议补充防篡改机制与上线前 AA 预跑。

08 · 实验设计重制：哈希分桶 + Pre-AA 全流程

用生产规范把整个实验重新设计一遍：样本量/功效 → 哈希分桶 → Pre-AA 门禁 → 主实验监控 → 决策规则，并用现有数据仿真验证管线。完整方案见 experiment_design.md。

方法论 · 历史数据上的效应估计：哈希分配与真实暴露（原分组）正交，因此取"哈希分配 == 实际暴露"的匹配子样本作为新实验人群——选择机制与（暴露、结果、协变量）独立，匹配子样本上的估计无偏，样本量约为一半。生产环境不需要这步（暴露直接跟随哈希分配），这是历史数据重放时的等价做法。
样本量设计（α = 0.05，功效 = 0.8，基线 11.87%，日流量 ~402 用户）

低流量 + 小 MDE = 跑不完的实验：+5% 相对提升需要约 237 天。现实解法是 CUPED / 分层 / 目标用户圈选，或接受更大的 MDE。

Pre-AA 门禁表（对照组池哈希 A/A × 500 次）

门禁全过 → 管线健康，可以上线 AB。预跑 AA 是上线前的 pipeline gate，回顾式 AA（07 附录）是分析时的数据体检，两者都做。

哈希分组均衡校验（salt = ab-test-web-v1）

哈希分桶占比 49.99%（SRM 卡方 p = 0.944）→ 分组干净，人口属性全均衡。

回顾性 AA 校验：还原原始实验的分组机制（先哈希分桶 → 确认组别 → 再放量）

原始实验的分配流程是先哈希分桶确认组别、再放量实验，数据只留下 group 结果字段；用 user_id 复现该哈希机制（忽略 group）：哈希与原始分组正交（独立性卡方 p = –），桶间 converted 差 –（p = –）→ 分桶机制无偏。全样本（含已暴露）pre-AA 仿真假阳性率 – ≈ 理论 5%。对照：真实实验组差 +6.08pp（p ≈ 0）——只有真实暴露才携带处理效应。

主实验效应估计：原实验 vs 哈希分桶 + 匹配子样本

匹配子样本上的估计 +6.12pp 与原始估计 +6.08pp 几乎重合（原始估计落在新 CI 内）→ 哈希分桶链路复现了原始结论，效应估计无偏。样本减半后 z 从 46.3 降到 33.0，仍远高于 1.96。匹配子样本内均衡校验全部通过（年龄 SMD≈0，分类卡方 p > 0.05）。

监控轨迹：匹配子样本累计检验 p 值随天数的变化（对数刻度）

匹配子样本（样本减半）下，第 3 天累计检验即显著（p < 0.05）——比全量样本的第 1 天慢，正是样本量与检测速度关系的体现。生产上仍需跑满最小时长（≥ 2 个完整自然周），防新颖效应与周内波动——统计显著 ≠ 业务稳健。

关键教训 · 分配 ≠ 暴露：哈希分桶是对全量用户做的（每个人都拿到了桶号）；但用户实际看到的页面由原实验决定，哈希只是"假如"。若朴素地把全量用户按哈希臂直接比较：两臂都是约 50% 旧页 + 50% 新页的同质混合物，期望转化率完全相同 → 效应从 +6.08pp 稀释到 +0.03pp（期望为 0）。匹配子样本不是"只给一半人分桶"，而是只保留「哈希说的分组 == 实际看到的页面」的用户（约一半）——只有他们拥有与哈希设计一致的观察结果，另一半用户的反事实结果在历史数据中不存在。生产环境没有这个问题：暴露直接跟随分配（全量服从），无需匹配、没有稀释；这也是生产上必须监控 SRM 与合规率的原因。

07 · 附录：实验工程自查

结论可信还需要实验工程过关。用现有数据回测四个环节：AA 校准（假阳性率）、SRM 监控（样本率匹配）、时段效应、SUTVA（单元完整性）。

AA 测试校准：真实数据上的假阳性率检验

将对照组随机切成两半做 2000 次 AA 测试，p < 0.05 的比例 = 假阳性率。若检验流程无偏差，应 ≈ 5%（均匀分布下的理论值）。对照组 5.0%、实验组 5.1% → 流程校准通过。

SRM 监控：对照组每日占比（14 日滚动）

整段周期内占比稳定在 50% 附近（std = 0.2%）→ 无样本率不匹配，分组没有被污染。

时段效应：按星期 × 转化率

新页优势在一周内每天成立，无星期维度翻转。

时段效应：按小时 × 转化率

新页优势在全天 24 小时一致成立，无时段翻转。

SUTVA / 用户单元完整性

每个用户仅出现一次、且只属于一个分组 → 无重复污染，单元间干扰（interference）风险低，满足 SUTVA 假设。
